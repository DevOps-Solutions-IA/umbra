Lectura conjunta obligatoria: [informe, referencias, límites y evidencia](2026-09-30-product-reality-audit.md). Cada fila tiene **una** clasificación para el alcance que nombra. Las filas P12/P40 separan expresamente el núcleo emulado del recorrido productivo. `IMPLEMENTED_CONNECTED_UNPROVEN_PHYSICAL` significa conectado a un consumidor productivo, no “hay conexión a Internet”. `PHYSICALLY_FAILED` conserva el resultado de uso reportado por el usuario, sin atribuir una causa de radio o criptografía no medida.

# Seguridad de UMBRA

Esta base no está aprobada para conversaciones sensibles. Leer `docs/SECURITY.md` y
`docs/RELEASE_CHECKLIST.md`.

No publicar claves, tokens, datos de usuarios, identidades reales, capturas de conversaciones
ni reproducciones con secretos en issues/PRs/artefactos. Utilizar casos sintéticos.

El propietario debe configurar un canal privado de reporte y responsables antes de una
release. Esta preparación no habilita por sí sola ese canal, reglas de branch protection,
GitHub Advanced Security ni auditoría externa. No declarar esas capacidades activas.
